What makes this fork different from vanilla Telegram iOS client:

1. Add explicit system default browser as option to open URLs - DONE
2. Add option to completely hide UI elements related to stories
3. Do not show inidcator of unread messages if given contact is not a group or private person. I.e if something is discussion chat with more than 2 members - do not show any indicator this chat has new messages.
4. Given chat that exists in Topics form allow to show exclusively unread counts from certain topics.
